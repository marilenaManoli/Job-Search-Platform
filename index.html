This app can't run in the background, but here's the recommended routine:
Mon morning: Run a job scan, review 5+ new listings.
Tue–Thu: Send 1–2 targeted applications with tailored letters.
Fri: Do recruiter outreach (1–2 messages) + update tracker.

Set a calendar reminder in Google/Apple Calendar: "Swiss job search — 30 min" on Mon + Fri each week until September.
